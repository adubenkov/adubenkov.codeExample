# BACKLOG — идеи, chore-очередь, находки

> Единственная точка входа задач (поток идёт через оркестратора). Посеян
> process-init. Формат строк держи машинно-грепаемым.

## Идеи (разбираются на груминге)

- `<дата> · <суть> · <источник>`

## Chore-очередь (метка chore — manager подхватывает параллельно волне)

- `<дата> · <мелочь без риска> · <файл:строка>`

## Побочные находки агентов

- `<дата> · <суть> · <файл:строка> · <кто нашёл>`

## CONFLICT (противоречия документов — не разрешать молча)

- `<дата> · <док А против дока Б> · <что противоречит>`
